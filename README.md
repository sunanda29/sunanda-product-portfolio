# Sunanda Product Portfolio

React + Vite + Tailwind CSS portfolio.

## Local setup
1. Install Node.js 20.19+ or 22.12+.
2. Run `npm install`.
3. Run `npm run dev`.
4. For a production check, run `npm run build`.

## GitHub / Vercel
Upload this project to a GitHub repository. In Vercel, import that repository. Vercel should detect Vite automatically; build command is `npm run build`, output directory is `dist`.
